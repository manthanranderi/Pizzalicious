🍕 Pizzalicious

Pizzalicious is a modern and responsive pizza restaurant website created using HTML, CSS, and Bootstrap. The project is designed to provide an attractive user experience while showcasing pizza products, special offers, and restaurant information.

🚀 Features
Responsive Design
Modern User Interface
Bootstrap Framework
Hero Banner Section
Navigation Menu
Pizza Product Showcase
Promotional Offers
Contact Information Section
Social Media Integration
Mobile Friendly Layout
🛠️ Technologies Used
HTML5
CSS3
Bootstrap 5
Font Awesome
Bootstrap Icons
📂 Project Purpose

This project was developed to practice frontend web development skills and create a professional restaurant landing page. It demonstrates responsive layouts, component structuring, and modern website design techniques.

📱 Responsive Support

The website is optimized for:

Mobile Devices
Tablets
Laptops
Desktop Screens
